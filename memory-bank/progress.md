## 未决问题

- GitHub 未能识别 `LICENSE` 的许可类型（显示 NOASSERTION）：文件是完整的 GPL-3.0 条款，但缺少末尾的“How to Apply”附录，与 GitHub 的模板相似度不够。映场仓库的 `LICENSE` 同样如此。补上附录即可识别，条款不变。
- 内容层的歌词重合检查（与歌词逐行比对）目前只在映场导入 / 导出时进行，自动检查做不到（仓库不存歌词）；依靠投稿清单与人工审核。
- 与映场 Swift 读取器仍不一致的极少见情况（正常文件不受影响，样例不覆盖）：UTF-16 编码的文件（映场能读，按格式说明应拒绝）；`{name}` 或“！”后紧跟组合附加符；嵌套超过 512 层时的错误代码（两边都拒绝，代码不同）；端口超过 65535、链接中含转义换行等 URL 解析器差异（格式说明 §14 已注明）。映场的拆词对长串括号同样是二次复杂度，导入特制文件可能卡住，需在映场修正。
