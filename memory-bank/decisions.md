# 决定

| 编号 | 日期 | 决定 | 决定者 |
|---|---|---|---|
| C-001 | 2026-10-18 | **项目方向**：应援是社区内容，做一个与映场关联、但独立的社区项目，分三步：①格式定稳并上线简易的社区库（GitHub 仓库，Pull Request 投稿、维护者审核、配下架规则，不自建服务器与账号）；②映场接入社区库（浏览、按歌匹配下载、分享链接导入）；③独立的静态网页编辑器（浏览器中选择本机音频、本机分析节拍并打轴，不上传音频、不接流媒体）。 | 维护者 |
| C-002 | 2026-10-19 | （网页托管部分已由 C-008 改为 Cloudflare Pages）**名称与仓库**：项目名 CheerBook；一个公开仓库，格式说明、社区库与网页编辑器同仓，网页用 GitHub Pages 发布。 | 维护者 |
| C-003 | 2026-10-19 | **共享方式**：格式写成 JSON Schema 并配合成样例，内置 MIX 库是一份 JSON，作为映场、网页编辑器与其他读取方的唯一来源；各平台各自实现校验并跑同一组样例，结果必须一致。`spec/` 的权威副本在本仓库。 | 维护者 |
| C-004 | 2026-10-19 | **许可**：代码 GPL-3.0-only（网页编辑器会使用 Mineradio 舞台代码）；格式说明与 Schema CC0；内置 MIX 库 CC0，署名“应援圈传统”；社区投稿默认 CC BY 4.0，投稿时可另选。 | 维护者 |
| C-005 | 2026-10-19 | **治理**：起步由维护者一人维护；格式、不含歌词、去重等由 GitHub Actions 自动检查；权利人下架请求 7 天内处理，先下架后核实。 | 维护者 |
| C-006 | 2026-10-18 | **收录规则**：只收自己听写打轴、来源有明确开放许可或原作者同意的文件；文件不含歌词；“只是公开可见”的材料不收时间轴。内置 MIX 库只收偶像现场通用的 MIX，以多个相互独立的公开来源交叉核对为准，组合专属的口号不进内置库。 | 维护者 |
| C-007 | 2026-10-25 | **第一步上线细节**：①投稿可选许可限 CC0-1.0、CC-BY-4.0、CC-BY-SA-4.0，不写时自己听写的文件按 CC BY 4.0；②文件放在 `cheers/<艺人>/<歌名>/<文件名>.cheer.json`，文件夹名由文件中的艺人与歌名生成；③只收没有格式警告的文件，内容相同的文件不重复收录，同一作者同一首歌的新版本提示审核者；④`index.json` 由合并后的工作流自动生成并提交；⑤下架请求走 Issue 表单，不公开个人联系方式；⑥治理文件（本目录与 `AGENTS.md`）公开在本仓库。 | 维护者（2026-10-25 确认） |
| C-008 | 2026-10-25 | **网站由 Cloudflare Pages 托管**（取代 C-002 中的 GitHub Pages）：①先用 Cloudflare 提供的 `pages.dev` 子域名，以后可再绑定自己的域名；②Cloudflare Pages 连接本仓库，`main` 更新后自动构建（`node tools/build-site.js`，输出 `_site`）；③网站内容由仓库生成：按艺人与歌名浏览收录的应援（可下载）、通用 MIX 页，以及机器可读的 `index.json`、应援文件、Schema 与 MIX 库；④网站不加载其他站点的资源，不设访问统计，投稿内容一律转义，页面不含内联脚本。 | 维护者（2026-10-25） |
