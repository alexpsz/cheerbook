# 下架规则

CheerBook 只收投稿者自己听写、或有开放许可 / 原作者同意的应援时间轴，文件不含歌词。即便如此，仍可能有文件侵犯了你的权利，或是未经同意从你的作品转来的。遇到这种情况，请告诉我们。

## 谁可以提出

- 歌曲、编舞、官方应援法等内容的权利人或其代理人；
- 某个文件所依据的 call 表、视频等材料的原作者；
- 文件的投稿者本人（撤回自己的文件）。

## 怎样提出

在本仓库 [新建 Issue](https://github.com/alexpsz/cheerbook/issues/new/choose)，选择“下架请求”，写明：

1. 要下架的文件路径或链接（可以是多个）；
2. 你与这些内容的关系（权利人、原作者、投稿者等）；
3. 理由，例如它转自你的哪份作品。

不需要提供身份证件、住址等个人信息；如需私下沟通，请在 Issue 中说明，维护者会回复联系方式。

## 处理方式

- 维护者在收到请求后 **7 天内**处理，**先下架、再核实**：先从仓库当前版本与 `index.json` 中删除相关文件，再与提出者和投稿者核对。
- 核实后确认无误的，文件不再收录；确认请求有误的（例如文件确为投稿者原创），维护者会说明理由，经提出者同意或补充说明后再恢复。
- 已删除的文件仍可能留在 Git 历史与他人下载的副本中。如需从仓库历史中清除，请在请求中说明，维护者会另行处理。

处理结果会在原 Issue 中回复并关闭 Issue。
