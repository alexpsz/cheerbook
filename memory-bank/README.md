# memory-bank

项目的决定与状态，供维护者与 Agent 接手时读取。

| 文件 | 内容 | 更新 |
| --- | --- | --- |
| `decisions.md` | 产品与社区规则的决定 | 新决定加一行；改变既有决定时新增一行并把旧行标“已取代”，不删除 |
| `progress.md` | 当前状态、最近完成、下一步、未决问题 | 每完成一项更新；区分已验证与未验证 |

接手顺序：`AGENTS.md` → `progress.md` → `decisions.md` → `CONTRIBUTING.md` 与 `docs/` → `spec/README.md`。
