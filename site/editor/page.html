三步做一份应援

  1. 选择本地音频：歌曲只在你的浏览器里播放和分析节拍，不会上传。
  2. 加载歌词：导入或粘贴 LRC，或点“在线查找”从 LRCLIB 查询。歌词只用来对时间，不会写进应援文件。
  3. 边听边点：按住成员按钮（或数字键 1–9）记录演唱段落，M / C / N 记录 MIX、call、提示；右侧 MIX 库一点就插入。

草稿自动保存在这个浏览器里。做好后“保存到本机”，或“分享 / 投稿”到 CheerBook。
